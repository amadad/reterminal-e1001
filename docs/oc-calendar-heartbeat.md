# Calendar heartbeat: keep `calendar.md` fresh

The reTerminal `CalendarProvider` reads `~/reterminal-content/family/calendar.md`
and renders slot 0. In the Kunst/OpenClaw deployment, OpenClaw owns this file:
it should periodically fetch the household calendar, normalize it into
kitchen-friendly markdown, and write the file atomically. Humans should not
have to maintain `calendar.md` by hand.

The display pipeline itself does not talk to Google Calendar, iCloud, or any
other calendar API. Calendar auth/export failures belong upstream in the
OpenClaw scheduler/exporter; the reTerminal publisher should keep serving the
last-good markdown render.

## Example OpenClaw scheduled task

Add a task to your scheduler of choice:

```text
## refresh-kitchen-calendar (every 20 min)

Pull the household calendar and write ~/reterminal-content/family/calendar.md
or the machine-specific path named by the local provider manifest.

Steps:
1. Fetch events from your calendar source.
2. Render the result into the file format below — one section per absolute date.
3. Atomic write: write to calendar.md.tmp, then rename to calendar.md.

Failure handling: if the calendar fetch errors, do not touch calendar.md. Log
the error and let the display keep showing the last-good calendar.
```

## `calendar.md` format

Headers are absolute dates. The renderer asks `date.today()` at render time and
only draws the matching `## YYYY-MM-DD` section under the TODAY column (and
`today + 1` under TOMORROW). Sections for other dates are kept but ignored. A
`## Notes` section is also ignored and is a good place to mark the file as
machine-generated.

```markdown
# Today

Today + tomorrow agenda for the kitchen display (slot 0). Renderer reads
`## YYYY-MM-DD [Day]` sections and picks the matches for today/tomorrow at
render time. Auto-generated from a calendar exporter — do not edit by hand if
your exporter overwrites this file.

Format per line: `- HH:MM[am|pm] Label [@who]`. The time prefix is optional
(omit for all-day items). The `[@who]` tag is optional and lowercase (for
example `[@kid1]`, `[@family]`); `(Name)` is also accepted as a who shortcut.

## 2026-05-08 Fri

- 9:30am Piano [@kid1]
- 12:00pm Family lunch
- 4:00pm Baseball practice [@kid2]

## 2026-05-09 Sat

- 8:00am School
- 6:30pm Movie night

## Notes

Auto-generated by a local calendar exporter. Last refresh: 2026-05-08 09:30.
```

## Why absolute dates?

The retired `## Today` / `## Tomorrow` headers were date-relative, so any
moment between exports the labels lied: a Tuesday-written file claimed
Tuesday's events were "today" forever after, with no signal beyond a stale-mtime
pill. Absolute dates make the file's semantics correct regardless of when it
was written. If the exporter dies, the today column simply goes empty and is
labeled with the actual date — visible failure instead of confident lying.

`reterminal lint` flags retired `## Today` / `## Tomorrow` headers as a
migration error, and the renderer shows a notice ("retired calendar.md
schema") if a file uses only the legacy schema.

## Cadence

20–30 minutes is a good default. Faster wastes calls; slower means late-added
appointments may appear too late. The reTerminal pipeline reacts within about a
second of a file write when running with `publish --watch`, so end-to-end
latency is bounded by the exporter cadence.

## Why this is outside reterminal

Failure isolation. If calendar auth expires or a provider has an outage:

- The breakage stays in the exporter/scheduler.
- `calendar.md` does not get corrupted.
- The reTerminal pipeline keeps running for the other slots.
- The display shows last-good events for past dates and an empty (but dated)
  today column — never yesterday's events labeled as today's.
